## Опыт по `chrome-ext` / странице просмотра видео

- Не путай popup расширения (`popup.html`) и страницу просмотра видео (`preview.html`): видео открывается в отдельной вкладке, это preview page, не popup.
- На странице просмотра видео путь к файлу показывать сверху на месте заголовка; футер использовать для статуса воспроизведения.
- Длинные файловые пути в preview UI должны отображаться целиком с переносом строк, без ellipsis.
- Плашка (overlay), которая отображается на целевых сайтах во время загрузки, поддерживает перетаскивание (drag-and-drop).
- Общие цвета расширения вынесены в `extension/shared/theme.css` через CSS переменные. Они должны подключаться во все UI компоненты, включая изолированные Shadow DOM (через селектор `:root, :host`).

## Что находится в проекте

- Это PHP CLI-проект `YTD`, реализация инструмента поверх `Symfony Console`.
- Основные точки входа:
  - `./bin/ytd`
  - `./ytd.php`
  - Composer bin из `./composer.json`: `bin/ytd`

## Архитектура проекта

- `ytd.php`
  - канонический bootstrap приложения, загрузка autoload и верхнеуровневый error handling
- `src/Bootstrap/RuntimeBootstrap.php`
  - runtime root, `.env`, пути к `proxy_rules.yaml`, каталоги загрузки, normalizing argv
- `src/Command/YtdCommand.php`
  - CLI-аргументы, сбор runtime options и делегирование сценариев
- `src/Service/RoutingService.php`
  - маршрутизация по hostname, секции `direct` / `local` / `remote`, CLI override
- `src/Service/YtDlpClient.php` и `src/Service/YtDlpCommandBuilder.php`
  - сборка и запуск команд `yt-dlp`
- `src/Service/DownloaderService.php`
  - одиночные загрузки, preflight, overwrite, cleanup временных файлов
- `src/Service/DoctorService.php`
  - проверка окружения и конфигов
- `src/Service/SingleVideoFlowService.php`
  - orchestration single-video сценария
- `src/Service/PlaylistFlowService.php`
  - orchestration playlist flow
- `src/Service/PlaylistService.php`
  - playlist detection, preflight, selection, summary и загрузка
- `src/Dto/*`
  - value objects и DTO для route/download/playlist/doctor
