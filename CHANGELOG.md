# Changelog

## [1.1.0] - 2026-07-11

### Added

- Кнопка "Показать в Finder" в overlay загрузки Chrome-расширения.
- Поддержка переменной окружения `YT_DLP_PATH` для кастомного пути к бинарнику.
- Скрипт `ytd-proxy` для обхода ограничений macOS Local Network Privacy.
- Утилиты для релизной сборки и динамического версионирования в расширении.

### Changed

- Обновлена документация: добавлен масштабный раздел по архитектуре в `README.md` и инструкции по прокси.
- Загрузка видео теперь по умолчанию использует лучшее качество (`best`), убраны жесткие привязки к MP4/1080p в расширении.
- Добавлено требование расширения PHP `pdo_sqlite` в `composer.json` и `README.md`.
- Добавлены новые MIME-типы для предпросмотра аудио.

### Fixed

- Наследование переменных окружения в Native Host.
- Авто-открытие файлов после скачивания в расширении.
- Корректное разрешение пути к `ffmpeg` при запуске из расширения.
- Запись сырых логов процессов для лучшего дебага Native Host.

## [1.0.1]

- Мелкие фиксы после первого релиза.

## [1.0.0]

- Первый стабильный релиз проекта `ytd-php`.
- Базовая CLI-обертка вокруг `yt-dlp`.
- Поддержка скачивания одиночных видео и плейлистов.
- Поддержка маршрутизации через прокси (`direct`, `local`, `remote`).
- Chrome-расширение с использованием Native Messaging.
