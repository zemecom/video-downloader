# Changelog

## [Unreleased]

### Added

- Поддержка извлечения cookies из профилей браузера через `YTD_COOKIES_FROM_BROWSER` (в `.env`) и CLI-флаг `--cookies-from-browser` (с возможностью отключения через `--no-cookies`) для обхода ограничений YouTube ("Sign in to confirm you're not a bot").
- Проверка статуса cookies в диагностике `DoctorService` (`php bin/ytd --doctor`).
- Извлечение подробностей ошибок процессов `yt-dlp` в Native Host (`errorDetails`) и передача их в Chrome-расширение.
- Кнопка «Посмотреть ошибку» и модальное окно просмотра/копирования деталей ошибки в popup расширения и overlay на веб-страницах.
- Команда `make update-ytdlp` в `Makefile` для быстрого обновления `yt-dlp` в виртуальном окружении и через Homebrew.
- Настраиваемый таймаут сокета `YTD_SOCKET_TIMEOUT` (по умолчанию 30с) в `YtDlpCommandBuilder` для предотвращения ошибок `Read timed out` на медленных ресурсах.
- Проверка доступности локального сокета прокси (`PROXY_LOCAL`) в диагностике `DoctorService` (`php bin/ytd --doctor`).
- Автоматическая ротация лога `logs/native-host.log` при достижении 5 МБ.
- Воспроизведение скачанного видео в браузере автоматически стартует с текущей позиции (таймкода) на странице источника (YouTube и другие HTML5-видеоплееры) с использованием стандарта Media Fragment URI (`#t=...`), синхронизацией `loadedmetadata` и надежным получением времени через `chrome.scripting` API.

### Fixed

- Устранена ошибка скачивания видео YouTube `Sign in to confirm you’re not a bot` благодаря использованию сессии и cookies браузерного профиля.
- Устранена потеря текста ошибок при завершении процессов в `NativeHostJobRunnerService`, теперь детали ошибок (`errorDetails`) надежно парсятся из логов и буферов процесса.

- Повторные попытки при ошибке YouTube `HTTP 403 Forbidden` сбрасывают закэшированный `info.json`, запрашивают свежие ссылки по URL видео и очищают кэш `yt-dlp` с небольшой паузой, обеспечивая корректную докачку.
- Исключен шумный ежесекундный дебаг-лог операций поллинга (`get_job_status`, `list_recent_downloads`) в `native-host.log` (доступен через `YTD_DEBUG=1`).
- Добавлен глобальный fallback `*` в `proxy_rules.yaml` и улучшены подсказки при отсутствии необходимых переменных прокси в `.env`.
- Popup расширения остается открытым после запуска загрузки и восстанавливает состояние активной задачи.
- У отмененных и ошибочных загрузок больше не отображается активная анимация прогресса.
- Имена файлов в режиме "Только аудио" больше не содержат разрешение исходного видео.
- Режим BEST для записей YouTube, ранее бывших live, выбирает лучшие отдельные видео- и аудиопотоки вместо пониженного muxed HLS-формата.
- Предварительный расчет имени теперь использует тот же выбранный формат, что и загрузка: после режима BEST можно скачать FHD-версию того же ролика.
- Native Host показывает пропуск существующего файла как отдельный финальный статус и не добавляет его в историю как новую загрузку.
- Время в логах и состояниях native host учитывает настроенный часовой пояс `YTD_TIMEZONE`.
- Повторная задача с уже существующим файлом добавляет его в историю и позволяет открыть файл из overlay расширения.
- Расширение прекращает опрашивать native host после терминального статуса `skipped`.

## [1.1.0] - 2026-07-11

### Added

- Кнопка "Показать в Finder" в overlay загрузки Chrome-расширения.
- Поддержка переменной окружения `YT_DLP_PATH` для кастомного пути к бинарнику.
- Скрипт `ytd-proxy` для обхода ограничений macOS Local Network Privacy.
- Утилиты для релизной сборки и динамического версионирования в расширении.

### Changed

- Обновлена документация: добавлен масштабный раздел по архитектуре в `README.md` и инструкции по прокси.
- Загрузка видео теперь по умолчанию использует лучшее качество (`best`), убраны жесткие привязки к MP4/1080p в расширении.
- Добавлено требование расширения PHP `pdo_sqlite` в `composer.json` и `README.md`.
- Добавлены новые MIME-типы для предпросмотра аудио.

### Fixed

- Наследование переменных окружения в Native Host.
- Авто-открытие файлов после скачивания в расширении.
- Корректное разрешение пути к `ffmpeg` при запуске из расширения.
- Запись сырых логов процессов для лучшего дебага Native Host.

## [1.0.0]

- Первый стабильный релиз проекта `ytd-php`.
- Базовая CLI-обертка вокруг `yt-dlp`.
- Поддержка скачивания одиночных видео и плейлистов.
- Поддержка маршрутизации через прокси (`direct`, `local`, `remote`).
