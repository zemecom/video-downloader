# Contributing

Спасибо за интерес к PHP-версии проекта.

## Быстрый старт для разработки

1. Установи PHP 8.5+ и Composer.

2. Установи зависимости проекта:

```bash
make install-deps
```

3. При необходимости установи внешние runtime-зависимости:

- `yt-dlp`
- `ffmpeg`

4. Создай локальные конфиги:

```bash
cp .env.example .env
cp proxy_rules.example.yaml proxy_rules.yaml
```

или просто:

```bash
make init
```

5. Переключись на рабочую ветку `dev` и синхронизируй её с `origin/dev`.

6. Прогони основные проверки:

```bash
make test
make lint
```

7. Если хочешь вручную проверить сетевые сценарии, заполни `TEST_*` в `.env` и запусти:

```bash
make test-integration
```

## Ветки и публикация

- Основная и рабочая ветка проекта: `dev`.
- Контрибьюторские коммиты делаются в `dev`.
- Публикация в GitHub идёт напрямую через `origin/dev`.

## Что важно

- Не меняй существующие CLI-флаги без веской причины.
- Unit-тесты должны оставаться независимыми от сети.
- Integration-проверки считаются ручной частью workflow и не заменяют обычные unit/lint проверки.
- Если меняется поведение CLI, конфигов или install story, обновляй документацию в том же PR.

## Pull Requests

- Коротко опиши, что именно меняется и зачем.
- Если меняется поведение CLI или конфигов, обнови `README.md`, примеры и подсказки.
- Перед PR убедись, что локально проходят `make test` и `make lint`.
- Если PR затрагивает integration story, отдельно укажи, какие сценарии проверялись вручную.
