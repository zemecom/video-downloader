# Инструменты разработки (Dev Tools)

В проекте настроен мощный стек инструментов для поддержания качества кода на уровне Senior.

## 1. Качество кода и стандарты

### PHP CS Fixer

- Автоматически форматирует код в соответствии со стандартами (PER-CS, Symfony).
- Запускается: `make lint` (только проверка) или `make lint-fix` (исправление).

### PHPStan

- Инструмент статического анализа кода. Находит ошибки типов, неверные вызовы методов и логические баги до запуска кода.
- Запускается: `make lint`

### Rector

- Утилита для автоматического рефакторинга и обновления синтаксиса до возможностей современного PHP (8.4).
- Правила настроены в `rector.php`.
- Запускается: `make rector` (или `make rector-dry-run` для предпросмотра).

## 2. Архитектура

### Deptrac

- Защищает архитектурные границы слоев приложения. Гарантирует, что никто не добавит запрещенную зависимость (например, запрос к базе данных или обращение к CLI прямо из DTO).
- Запускается: `make deptrac`.

## 3. Тестирование

### PHPUnit

- Базовый фреймворк для написания Unit и Integration тестов.
- Запускается: `make test`

### Infection (Мутационное тестирование)

- Проверяет *качество самих тестов*. Он вносит мелкие ошибки (мутации) в исходный код (меняет `+` на `-`, `<` на `<=`) и смотрит, упали ли тесты. Если тесты не упали — значит, они плохо проверяют логику.
- Настройки: `infection.json5`.
- Запускается: `make infection`.
- *Примечание: Для локального запуска требует расширение PCOV или Xdebug.*

## 4. Сборка и Поставка

### Box (Humbug Box)

- Упаковывает всё PHP-приложение вместе с `vendor/` в один исполняемый `.phar` файл.
- Настройки: `box.json`.
- Запускается: `make build` (артефакт появится как `ytd.phar`).

## 5. Автоматизация процессов (DX и CI/CD)

### GrumPHP

- "Злой" страж твоих Git-коммитов. Работает как `pre-commit` hook.
- При попытке сделать `git commit`, он параллельно запустит PHP CS Fixer, PHPStan и PHPUnit. Если хотя бы один упадет — коммит будет отменен.
- Конфиг: `grumphp.yml`.

### Dependabot

- Настроен через `.github/dependabot.yml`.
- Еженедельно проверяет обновления Composer и npm пакетов и создает Pull Requests, если вышли новые версии.

### Release Drafter

- Настроен через `.github/release-drafter.yml`.
- Автоматически формирует черновик релиза на GitHub на основе слитых Pull Requests, аккуратно сортируя их по категориям (Features, Bug Fixes, Maintenance).

## 6. Фронтенд (Chrome Extension)

- В директории `chrome-ext` настроен **ESLint** (проверка качества JS) и **Prettier** (форматирование HTML, CSS, JS).
- Команды запуска: `npm run lint` и `npx prettier --write .`.
