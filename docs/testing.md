# Тестирование и проверка качества кода (Testing & Mutations)

В проекте настроен многоуровневый контур тестирования, гарантирующий стабильность работы CLI-приложения и интеграций.

---

## 1. Разделение тестовых контуров

Тесты разделены на две группы: быстрые Unit-тесты и сетевые Integration-тесты.

### Unit-тесты (Быстрые)

Unit-тесты проверяют чистую логику работы компонентов в изоляции (без выполнения реальных сетевых запросов и скачиваний).

- Тестируют: логику парсинга аргументов, маппинг плейлистов, валидацию конфигураций, логику разбора вывода `yt-dlp`.
- Запуск:

  ```bash
  make test
  ```

  или напрямую через PHPUnit:

  ```bash
  vendor/bin/phpunit --testsuite=Unit
  ```

### Integration-тесты (Сетевые / Тяжелые)

Проверяют реальное сетевое взаимодействие и корректность интеграции с внешними утилитами (`yt-dlp`, `ffmpeg`).

- По умолчанию эти тесты пропускаются или используют моки, если не заполнены тестовые URL в `.env` (переменные `TEST_URL_DIRECT`, `TEST_URL_LOCAL`, `TEST_URL_REMOTE`).
- Запуск:

  ```bash
  make test-integration
  ```

  или напрямую через PHPUnit:

  ```bash
  vendor/bin/phpunit --testsuite=Integration
  ```
