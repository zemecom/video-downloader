# Продвинутая установка

Если базовая установка через `make init` (описанная в главном `README.md`) тебе не подходит, здесь описаны альтернативные способы.

## Ручная установка без Makefile

Сначала установи внешние runtime-зависимости вручную:

- `yt-dlp`
- `ffmpeg` (нужен для объединения video/audio потоков, включая режим `--fast`)

Затем поставь PHP-зависимости проекта через Composer:

```bash
cd /path/to/video-downloader
composer install
cp .env.example .env
cp proxy_rules.example.yaml proxy_rules.yaml
```

Этот путь подойдёт, если тебе удобнее использовать только Composer и обычные shell-команды вместо утилит `make`.

## Сборка и запуск в виде автономного PHAR-архива

Ты можешь собрать всё приложение в один независимый исполняемый `.phar` файл, который можно переносить и запускать без папки `vendor/` и вызовов `composer install` (хотя внешние зависимости `yt-dlp` и `ffmpeg` всё равно должны быть установлены в системе).

1. Собери PHAR-архив:

   ```bash
   make build
   ```

   В корне проекта появится файл `ytd.phar`.

2. Запусти его локально:

   ```bash
   ./ytd.phar https://youtu.be/example
   ```

3. (Опционально) Сделай его доступным глобально в системе:

   ```bash
   sudo mv ytd.phar /usr/local/bin/ytd
   chmod +x /usr/local/bin/ytd
   ```

   После этого ты сможешь использовать команду `ytd` из любой папки.

> [!NOTE]
> Скомпилированный PHAR-архив всё ещё будет искать файлы конфигурации `.env` и `proxy_rules.yaml`. Он ищет их сначала в текущей рабочей директории, откуда запущен скрипт, а затем в директории, где лежит сам PHAR-файл.
